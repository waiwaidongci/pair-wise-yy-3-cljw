# 岩芯样本切片实验室

恒温柜位管理与温漂转移台：每片切片只占一个柜位，柜位不得重复分配。

## 运行

```bash
npm start
```

访问 `http://localhost:3025`（可用 `PORT` 环境变量改端口）。

## 模块划分

- `src/decision.js` — 判定模块（纯函数）：2~8℃、湿度≤60% 的入柜判定；样本编号、钻孔、岩芯箱、切片编号变化导致柜位结论失效；可交付判定；列表/柜位台/履历共用的派生视图。
- `src/storage.js` — 存储模块：JSON 持久化与全部写操作，所有变更经串行队列“重读-修改-写回”，杜绝并发下柜位重复分配。
- `src/routes.js` — 路由模块：HTTP 适配，只做取参与响应。
- `src/page.js` — 前端页面。
- `server.js` — 入口。

## 业务规则

- **入柜登记**：柜位、温度、湿度、保管人；每片一个柜位，已占用（含待确认转移预留）的柜位不能再分配。
- **温漂判定**：温度不在 2~8℃（含边界）或湿度 >60%，判定为“待转移”，样本不可交付。
- **温漂转移台（两阶段）**：
  1. 申请转移须登记新柜位、接收人、原因及新柜温湿度；只预留新柜位，**确认前原柜位不释放**；
  2. 确认时一次性释放原柜位、建立新入柜记录并写履历；任何一步失败整体不落库；
  3. 取消则待确认记录整体删除，新柜位预留释放，不留半截记录。
- **结论失效**：样本编号、钻孔、岩芯箱或切片编号变化后，入柜编号快照与现状不符，柜位结论失效，需重新登记（复检）后方可交付；失效期间同样不可交付。
- **交付把关**：任一切片未入柜、温漂待转移、转移待确认或结论失效，交付均被拒绝并返回阻塞原因。
- **重载一致**：列表、柜位台、转移台、履历均来自同一份 `/api/state` 派生视图。
