# 岩芯样本切片实验室 · 恒温柜位

运行：

```bash
npm start
```

访问 `http://localhost:3025`。支持样本创建、切片任务、制片步骤记录，以及恒温柜位登记、
温漂转移和交付管控。

## 模块划分

| 文件 | 职责 |
| --- | --- |
| `rules.js` | 判定模块（纯函数）：温湿度合规（2–8℃、湿度 ≤60%）、身份指纹比对、柜位状态与交付准入判定 |
| `store.js` | 存储模块：JSON 文件持久化（临时文件 rename 原子写 + 变更互斥）、入柜/复查/转移/失效编排、列表与履历视图派生 |
| `server.js` | 路由模块：HTTP 接口与页面，不直接读写数据文件 |

## 柜位与转移规则

- 每片切片只占一个柜位；柜位被占用或有待确认转移预约时，不得再分配。
- 入柜登记柜位、保管人、温度、湿度。温度不在 2~8℃ 闭区间，或湿度 **超过** 60%（>60），
  切片进入“待转移”，样本不可交付。
- 温湿度复查可以更新状态：恢复合规则解除待转移，再次越限则重新进入待转移。
- 转移登记新柜位、接收人、原因及目标柜位温湿度。申请后原柜位 **不释放**，
  新柜位仅作预约；接收确认时登记新保管人与实测温湿度，旧记录关账、新记录开账一次性落盘；
  撤销或失败时不留半截记录，原柜位继续占用、新柜位恢复空闲。
- 样本编号、钻孔、岩芯箱或切片编号变化（身份指纹不一致），柜位结论立即失效：
  原柜位释放、待确认转移自动撤销，须重新入柜登记，履历保留。
- 全部切片处于合规在柜状态才允许“标记交付”，否则按钮锁定并列出阻断原因。
- 页面列表、柜位图、统计与每片履历全部由 `GET /api/state` 同一份持久化状态派生，刷新一致。

## API

- `GET /api/state` — 样本、柜位、每片柜位视图与履历、交付阻断、统计
- `POST /api/samples`、`POST /api/samples/:id/slices`
- `PATCH /api/samples/:id`（钻孔/岩芯箱等）、`PATCH /api/samples/:id/slices/:sid`（切片改号）
- `POST /api/samples/:id/slices/:sid/logs`
- `POST /api/samples/:id/slices/:sid/checkin`、`/readings`
- `POST /api/samples/:id/slices/:sid/transfers`、`/transfers/:tid/confirm`、`/transfers/:tid/cancel`
- `POST /api/samples/:id/deliver`
